# Yui · v0.1

用于 SillyTavern 的轻量玩具手机。优先从 **GitHub 安装为酒馆扩展**，后续在扩展管理中更新并刷新即可，不必反复导入 JSON。当前扩展发行号 0.1.2，功能仍为 v0.1 演示，新增外观美化。原 Tavern Helper / JS-Slash-Runner JSON 保留为备用，两者共用同一套界面源码。

**演示模式：不调用 AI，不保存聊天。** 产品现名 **Yui**，仍为 v0.1 演示阶段。银色侧框、矩形屏幕、实体 Home 键，配用户供图抠出的透明粉色挂绳。上下白边合计缩短约 37%，Home 在普通和紧凑模式都居中；移除右上与右下贴纸，保留下方左侧光环。主屏幕底部采用半透明应用 Dock：点爱心信封进入联系人列表，再点小桃进入聊天。一个虚构联系人、三个预置示例；发送只增加用户气泡，没有自动回复。关闭面板保留本次内存演示，禁用、重新加载或刷新清空。

## 美化与本机保存

主屏 Dock → **美化** → 选择“左上 / 右上 / 左下 / 右下 / 挂绳”。四角指机身上下白边的四个位置；装饰不拦截点击，Home 和关闭始终可操作。

- 可选36枚用户供图贴纸，以及原光环、原挂绳或不显示；各位置独立设置大小和旋转。挂绳从模拟壳体侧边挂孔垂下，绘制在屏幕前景层；左右挂点可切换，留出视口空间。
- **导入自己的图片**只读取你选中的 PNG/JPEG/WebP。单张上限2MB、最大4096×4096，处理后最长边512px。透明PNG/WebP适合贴饰；普通JPEG白底会保留。文件在本机解码后重新编码，不接收SVG或远程图片地址，不上传图片。
- 选择后实时预览；**保存外观**只写本浏览器同一酒馆地址下的 `yui-pocket.appearance.v1`，刷新/更新后保留。聊天不会保存。未点保存的预览只保留本次运行；不同设备、地址或浏览器不会自动同步。
- **恢复默认**恢复初始装饰并清除此键；其他宿主数据不受影响。禁用/卸载不会主动删除外观偏好，如需清除，先在美化中恢复默认再卸载。浏览器禁止存储或空间不足时会明确提示保存失败。
- 挂绳打开时仅摆动一次；系统开启减少动态效果时停止摆动。当前为视觉模拟，没有物理碰撞或拖拽自由摆放。

## 从 GitHub 安装、更新和禁用（推荐）

仓库：[yui-ovo/yui-pocket](https://github.com/yui-ovo/yui-pocket)。

1. **先在酒馆助手中停用旧 Yui / ruru 脚本**，不要同时启用两种安装方式。
2. 酒馆 → 扩展 → 安装扩展，粘贴 `https://github.com/yui-ovo/yui-pocket`，完成安装后刷新页面。这个入口安装的是本仓库根目录的 manifest.json 和 extension.js，不需要导入 dist 里的 JSON。
3. 点击右侧 Yui → 信息 → 小桃，开始演示。扩展版当前不依赖酒馆助手。
4. 以后本仓库发布修改后，在酒馆扩展管理中检查更新并更新 Yui，然后**刷新页面**应用新版。没有添加常驻联网检查；manifest 的 auto_update=false 不妨碍手动更新。
5. 禁用/卸载：到酒馆扩展管理中关闭/删除 Yui，并按宿主提示刷新。支持官方生命周期钩子的宿主会立即移除 Yui；没有钩子的旧版或分支宿主，需要刷新才能清理正在运行的旧模块。

已核实 SillyTavern 1.18.0 源码的 manifest、模块加载、钩子和 Git 更新逻辑；已做模拟测试，**没有在真实 SillyTavern/TauriTavern 执行安装**。TauriTavern 的扩展管理、网络访问和 WebView 行为仍需真机确认。

## 助手 JSON 导入与使用（备用）

GitHub 仓库只提交扩展构建 extension.js，不重复存放整份内嵌资源的 JSON。备用 JSON 在本地交付包中，或运行 npm run build 生成。

1. 在已安装并启用酒馆助手的 SillyTavern 中打开助手面板 → **脚本库**。
2. 使用脚本库的 **导入**，选择 `dist/yui.v0.1.json`。本次交付的 `outputs/yui.v0.1.json` 与它逐字节一致，可以直接选该文件。
3. 如果提示选择脚本库，选 **全局脚本**；本演示不需要角色/预设绑定。确认全局脚本库开关启用，再启用 **Yui · v0.1 演示 · 4S**。官方导入逻辑会默认禁用新导入项，需手动开启。升级时先停用旧版，再导入和启用新版，避免两条副本轮流争用同一入口。旧名字文件仍作为历史产物保留，本次只导入 yui.v0.1.json。
4. 点击屏幕右侧约三成高度的 **Yui** 入口 → 底部 Dock 的 **信息** → 联系人 **小桃**，然后输入文字并点 **发送**。
5. 聊天页左上 **信息** 返回联系人列表；列表左上 **主屏** 和底部圆形 **Home** 回主屏幕。页面之间切换保留消息和草稿，联系人摘要从同一份演示消息读取。机身右上 **×** / 手机内 **Escape** 关闭；重新打开先回主屏，未发送草稿在关闭时清空。不设置全屏遮罩。
6. 要彻底禁用，到助手脚本库关闭此脚本开关。入口和手机应消失。也可在停用后删除该脚本。

这不是普通扩展 JSON、角色卡 JSON 或正则 JSON，不要导入到这些入口。本轮没有配套正则。

格式核实基线：助手 **4.9.5**，commit `04a62b763513744b8cb3d85322f9b5c73bdf8a85`。已核实官方格式并完成模拟测试，**尚未在真实 SillyTavern / TauriTavern 执行导入**。旧版或分支版助手的导入兼容性待实测，详见 `SOURCES.md`。

## 构建和测试

需要 Node.js 22+ 和 npm。运行时无 npm 依赖；三个顶层开发依赖分别用于类型检查、打包和浏览器测试，版本锁在 package-lock.json。

```sh
npm ci
npm run build
```

构建生成 `dist/yui.v0.1.json`，代码、CSS、透明挂绳 PNG、信封 JPEG 和光环 PNG 的 data URL 全部嵌入 `content`，无远程 import、字体、图片或 CDN 依赖。`enabled` 默认 false。构建时执行字段、阶段禁用 API 与依赖图约束，JSON 解析通过不等于真实导入通过。

默认安装测试用 Chromium 后运行全部检查：

```sh
npx playwright install chromium
npm test
```

也可使用已有 Chrome，不下载测试浏览器。PowerShell 示例（路径按实际安装调整）：

```powershell
$env:RURU_BROWSER_PATH = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
npm test
```

`npm run build` 同时生成根目录 extension.js 和 dist/yui.v0.1.json；两种格式都内嵌图片和样式，无运行时远程 import。`npm test` 顺序执行 TypeScript 检查、构建、5 项 Node 产物测试和 23 项 Playwright 浏览器测试。测试服务器只监听 `127.0.0.1:4173`，仅暴露虚构页面和这两种构建；没有后端业务或数据库。端口须空闲。浏览器报告在 `work/browser-results.json`，截图在 `outputs/`。

可选本地目视演示：

```sh
npm run preview
```

在浏览器打开终端打印的本地地址，页面明确标注“模拟宿主”。它把 JSON 的 content 放入同源隐藏 iframe，用原生 iframe 删除模拟禁用。它不会加载真实助手的框架/脚本、不会接触真实聊天，不能证明真实宿主兼容。按 Ctrl+C 停止。

`npm run deliver` 将源码、文档和构建产物整理到 `outputs/yui-source/`，并生成供直接导入的 JSON 副本、使用说明副本和校验值；首次运行前应完成 `npm test`。

- 开关、空白拒绝、单次发送、连续空提交、20 次开关、同 iframe 重复执行、跨 iframe 替换、旧实例迟到卸载、就绪回调迟到均通过。
- 真正删除模拟 iframe 后，自己的根节点和登记监听器归零；关面板时该面板监听器移除，入口保留正常工作。

- 对构建代码的初始化、开关、发送、卸载拦截网络与 Storage API，观察到 0 请求、0 禁用 API 调用（允许读取专用外观键，聊天交互不写存储）。测试夹具获取本地 JSON 是夹具行为。
- 1280×900、375×667、320×568、375×340、667×375 的输入与关闭/发送按钮在边界内；长文本不横向溢出。另模拟布局高度 800、可视高度 340、偏移 180，输入仍可见；宿主强制 button/textarea 样式没有侵入内部。
- 已人工查看生成截图。这些是桌面浏览器模拟尺寸，不是手机真机截图。

## 已知限制

- 只有单个虚构联系人；每条最多 2000 个 UTF-16 码元。输入换行使用 Enter，发送使用按钮；未添加发送快捷键。
- 当前演示是全局内存界面，不与存档绑定；切换聊天时仍可能看到本次演示内容。它不是真实聊天记录，也不读取或写入存档。重新加载/禁用清空；真正存档与分支隔离属于 v0.2 起的工作。
- 尚无正文气泡、持久化、模型回复和剧情上下文注入。正文原位气泡是 v0.3 必做核心，详见 ROADMAP.md，不能以这个面板演示替代最终验收。
- 4S 是本次外形与早期 iOS 视觉参考，不是完整系统复刻。只有信息应用入口；状态栏时钟为打开时的本地时刻，信号/电量图形为装饰。短视口会压缩白边，此时不保持正常机身比例。
- 入口固定在右侧、暂不可拖拽，部分主题/扩展布局可能需要后续微调。非常小的可视高度下消息区会明显变短并滚动；低于已测的 340px 可视高度尚未保证布局。
- Yui 本身不主动请求网络。但核实版本的助手会在 iframe 初始化中注入 Vue、Vue Router 和日志脚本的 CDN 资源；本项目没有复制、调用或修改这些加载逻辑，因此不承诺整个助手环境离线。详见 SOURCES.md。
- 依赖同源父窗口 DOM、Shadow DOM 和助手 pagehide 生命周期；非标准 WebView 行为需实测。当前没有真实宿主测试失败记录，也没有把未验证项视为已通过。

## 工程职责

- `src/host.ts`：同源宿主访问、单实例、就绪/卸载、可视区域；助手入口挂载父窗口，扩展入口显式挂载当前窗口。
- `src/extension.ts` / `manifest.json`：轻量扩展入口和官方生命周期钩子；`extension.js` 是应提交到仓库的构建产物。
- `src/appearance.ts` / `src/beautify.ts` / `src/stickers.ts`：外观数据与专用本机存储、图片处理、美化界面和供图素材目录。
- `src/demo.ts`：唯一的临时演示消息集合，不是未来持久协议。
- `src/phone.ts` / `src/phone.css`：原生 DOM 界面与隔离样式。
- `src/assets/`：用户提供的内嵌信封图标、光环贴纸与本地抠图后的挂绳。完整透明抠图另交付 `outputs/yui-strap-cutout.png`；运行版本缩至 303×700，保持比例。旧 `ornaments.ts` 和十字图文件保留历史，已不被运行构建引用。
- `src/lifetime.ts`：监听器登记和移除。
- `scripts/`：打包、字段校验、局部模拟服务器、交付整理。
- `tests/`：虚构模拟宿主、JSON/依赖约束和浏览器行为验收。
